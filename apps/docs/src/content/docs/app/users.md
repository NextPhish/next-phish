---
title: User administration
description: Manage access to a NextPhish installation.
---

Administrators can open **Users** to search and review installation accounts. The list shows system role, organization membership and account status. Use **Create user** to enter a name and email, choose an administrator or member role, and select organization access where applicable.

The user actions can deactivate or reactivate an account. Permanent deletion is a separate destructive action with a confirmation preview; review its effect before proceeding. Organization-level membership and settings are also visible on the [organization detail](/app/organizations/) page.

The initial administrator is created through `/setup` before any user exists. Later users are managed through the app, not by repeating initial setup.
