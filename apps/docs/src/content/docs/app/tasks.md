title: Tasks
description: Keep a practical to-do list while managing many campaigns and their assets.
---

When several campaigns are in progress, small follow-up jobs are easy to lose. **Tasks** gives your organization a shared to-do board for those jobs. Use it to record what needs attention, how urgent it is, and when to revisit it. The columns show what is still to do, what is in progress, and what is finished.

For example, you might add these tasks during a busy week:

| Task title                                                | Why record it?                                                           | Related resource              |
| --------------------------------------------------------- | ------------------------------------------------------------------------ | ----------------------------- |
| Create the October awareness campaign                     | Keep the next campaign on the team's list before it exists in NextPhish. | None yet                      |
| Fix the security reminder template                        | Remember which message needs editing before the next send.               | Email template                |
| Add the new company mail account                          | Make sure the sending profile is ready before scheduling.                | Sending profile, once created |
| Investigate why the welcome page renders poorly on mobile | Capture a problem found during preview and come back to it.              | Page                          |
| Check the pilot campaign's unexpected clicks              | Follow up on a result that may have come from a mail scanner.            | Campaign                      |

You can also use a task to remind yourself to review a target group, verify a schedule, or send a test email. Give each card one clear action so it is easy to finish or hand over.

_The task form has a title, notes, status, priority, optional due date, and an optional link to a campaign or other item._

## Keep the board useful

1. Open **Tasks → Create task**. Write a title that starts with an action, such as `Fix the welcome email on mobile`.
2. Use the description for the problem, the expected result, and any detail a teammate would need. Set a higher priority when the task could delay a planned send. Add a due date when there is a real deadline.
3. If the task concerns an item already in NextPhish, choose its **Related resource type** and then select the specific campaign, schedule, page, email template, target group, or sending profile. Leave it as **None** for work such as creating a new campaign that does not exist yet.
4. Save the card in **Todo**. Move it to **In Progress** when someone starts, then to **Done** after checking the result. Open a card to update its notes or priority as the work changes.

Move tasks between visible status columns with the card's drag handle, or use its status selector. The drag handle supports pointer, touch and keyboard input: Space or Enter to pick up, arrow keys to move, and Escape to cancel. Use **Manage statuses** to tailor the board's workflow.

At the start of a work session, scan **Todo** for urgent jobs and due dates. Before publishing a campaign, check whether there are open tasks about its message, page, audience, or sending profile. Tasks belong to the selected organization, so switch workspaces to see another organization's board. A related resource helps you find the item; finishing a task does not automatically publish, schedule, or change the campaign.
